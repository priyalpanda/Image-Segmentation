Unsupervised pattern analysis — issue images

60 original photos from issue_eval/images only. No manual sorting — pure math.

Method (standard unsupervised computer vision)

  1. Feature extraction (CNN): Each row is one CLIP image embedding (L2-normalized). Captures semantic visual similarity (scene type, objects, layout) without using your segmentation labels.
  2. Clustering (K-Means): Images in the same cluster have similar embedding vectors (mathematically close in high-dimensional space).
  3. 2D maps (t-SNE / UMAP): Reduce high-dimensional embeddings to a scatter plot so you can see which photos sit near each other.

Backbone: CLIP ViT-B-32 (openai) · Vector size: 512 numbers per image · K = 5 clusters · Silhouette: 0.024

K-Means groups (every image in exactly one cluster)

Auto-selected k=5 for clearer groups (best silhouette was only 0.043 at k=3).

What to collect & how to train better

Data to collect

  • More photos like the issue set: many objects per image (10+ labeled instances).
  • Scenes with overlap (people in crowds, items on tables, parked cars close together).
  • Extra images containing: person, car, chair, cup, bowl — these appear most in failed cases.
  • Targeted shots for rarely detected classes: fork, orange, mouse, elephant, toothbrush, toilet, laptop.
  • Small objects at medium distance (utensils, sports gear, handheld items).
  • Same lighting and camera style as your deployment images (not only clean studio shots).

Training steps

  • Fine-tune YOLOv8-seg (or your seg model) on COCO-format labels with polygon masks.
  • Use mosaic / copy-paste augmentation to simulate crowded scenes.
  • Increase max detections per image and slightly lower confidence at inference for dense scenes.
  • Oversample training batches from high-FN images listed in this report.
  • Add class-focused epochs or loss weight for person and other top failure classes.
  • Validate on a held-out set of issue_eval-style crowded images, not only easy single-object images.

Metrics to watch

  • Recall per class (especially person, car, chair, cup, bowl).
  • Mask IoU on images with 10+ instances.
  • False negative rate = missed GT instances / total GT instances.
